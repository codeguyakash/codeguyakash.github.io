Secure Pass

Generate strong, secure passwords or memorable passphrases in one click. Secure Pass features right-click autofill into any password field and remembers your last generated secret. The simplest way to create robust credentials without leaving your browser.

  • One-click strong password generation
  • Right-click autofill into any input
  • Remembers last generated password
